# 全局创作底线

> 以下规则适用于所有语调、所有赛道、所有平台。任何生成内容必须逐条通过。

## 1. 证据真实性

所有引用的概念、研究、人物、作品**必须真实存在**。不允许编造研究、人名、年代、数据。

## 2. 证据必须织入正文

`evidence_pool` 列出的素材必须在 `scripts` 中实际使用。不允许证据池和正文脱节。

## 3. AI 痕迹规避

严格禁止以下 AI 典型表达：

- 「不是 X 而是 Y」对仗排比
- 「其实 / 我们 / 很多时候 / 一直以来」等模糊群体修辞
- 「温柔的 / 治愈的 / 有质感的 / 高级的」等空泛形容词
- 「请记得 / 愿你 / 希望你」等虚浮祝福
- 强行升华金句结尾
- 三段式排比对仗

## 4. 内容原创

禁止抄袭已发表段落、金句、网络热梗。

## 5. 作者视角

以具体作者口吻写作，不要标准化 AI 语气。每条内容读起来应该像「一个人写的」，不像「一个模型生成的」。

## 6. 评分必须有依据

每个分数必须附具体加分点和扣分点，不能只有数字。

## 7. AI 痕迹自检（强制两步法）

### Step 1 — 扫描（必须逐条核对，命中即记录原句）

| 序号 | 模式 | 示例 |
|----|----|----|
| P1 | "不是X而是Y"对仗 | "这不是焦虑，而是觉醒" |
| P2 | 三段排比/对仗 | "看见自己，理解自己，成为自己" |
| P3 | 模糊群体修辞 | "我们""其实""很多时候""一直以来" |
| P4 | 空泛形容词 | "温柔的/治愈的/有质感的/高级的/松弛的" |
| P5 | 虚浮祝福 | "愿你/请记得/希望你" |
| P6 | 升华式金句结尾 | "毕竟，生活本就是一场……" |
| P7 | 名词化空话 | "××的本质是××""一种生活的姿态" |
| P8 | 翻译腔 | "在我看来""值得一提的是""不得不说" |
| P9 | 万能起手式 | "其实，……""说到底，……" |
| P10 | 抽象动词 | "赋能/拥抱/治愈/疗愈/共振" |

### Step 2 — 改写

对每条命中的原句，给出改写后的版本，并替换正文中的对应位置。
最终 `detected_patterns` 数组结构：
```
[{"pattern": "P1", "原句": "...", "改写": "..."}]
```
若全部 10 项扫描后均未命中，detected_patterns 填：
```
[{"pattern": "none", "scan_evidence": "P1-P10 已逐条扫描，未发现"}]
```
单纯填"无明显AI痕迹"视为未执行自检，内容判不合格。
